# おてほん

ピアノの楽譜の写真やPDFを読み取り、楽譜どおりに鳴らす、Mac用のローカルWebアプリ。

## 必要なもの

- macOS
- [uv](https://docs.astral.sh/uv/)
- [Claude Code](https://claude.com/claude-code)（`claude` を起動して `/login` 済みであること。校正に使う）
- インターネット接続（ピアノ音源と描画ライブラリをCDNから読み込む）

## 起動

```bash
uv run server.py
```

ブラウザで http://localhost:8765 を開く。

## 使い方

1. 楽譜の写真（JPEG・PNG・HEIC）かPDFを画面に置き、曲名を付けて「読み取る」。
2. 読み取りが終わると楽譜が出る。再生ボタンかスペースキーで鳴らす。
3. 本と違って聞こえるところは、校正欄に言葉で書くと直る（例: 12小節目の右手、最初のファはシャープ）。

再生では、テンポ、右手・左手だけの再生、小節範囲のループ、メトロノームが使える。
リピート、1番・2番括弧、D.C.・D.S.・Fine・Coda は楽譜どおりの順にたどる。

## しくみ

1. [homr](https://github.com/liebharc/homr) が画像を MusicXML にする（ローカルで実行）。
2. Claude Code が写真と見比べて MusicXML を直す（サブスクリプションの範囲で実行）。
3. ブラウザが OpenSheetMusicDisplay で楽譜を描き、Tone.js で鳴らす。

曲は `library/` に保存される。

## 制約

- 認識は完全ではない。Claude が推測で入れた値（数字のないテンポなど）は校正欄に「推測」と出る。
- サーバーは `127.0.0.1` だけで待ち受ける。認証はないので、他の端末には公開しないこと。
- Claude による校正は1ページあたり1〜2分かかる。
